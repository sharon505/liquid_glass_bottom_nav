# liquid_glass_bottom_nav

A customizable floating liquid-glass bottom navigation bar for Flutter with smooth animated destinations and an independent action button.

## Features

- Liquid glass navigation effect
- Smooth animated selected item
- Circle and tab/pill navigation styles
- Independent floating action button
- Customizable glass properties
- Customizable colors
- Customizable radius
- Selected and unselected icon styles
- Optional labels
- Optional shadows and borders
- Tooltip support
- Semantics support
- SafeArea support
- PageView friendly
- Highly configurable animation behavior
